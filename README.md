# herdr-plugin-agent-title

Publishes the native session title generated by Codex or Claude Code as Herdr
pane metadata. It avoids a second model call and updates correctly when a new
agent session starts in an existing pane.

## Install

```sh
herdr plugin install oyoshot/herdr-plugin-agent-title --yes
herdr integration install codex
herdr integration install claude
```

Plugin installation builds the Rust binary and registers managed hooks in
Codex and Claude Code. Existing unrelated hooks are preserved.

## Commands

```sh
target/release/herdr-plugin-agent-title install-hooks
target/release/herdr-plugin-agent-title uninstall-hooks
target/release/herdr-plugin-agent-title doctor
```

Set `HERDR_AGENT_TITLE_DEBUG=1` to print hook errors to stderr.

## Compatibility note

Codex titles are currently read from its local read-only state database. The
database is an internal implementation detail, so the plugin checks the schema
at runtime and falls back to the submitted prompt when the title columns are not
available. Claude titles are read from the hook input and session transcript.
